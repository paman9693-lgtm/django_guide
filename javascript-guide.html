1. JavaScript kya hai?

JavaScript ek programming language hai. Browser mein ye web page ko interactive banati hai; Node.js ke saath server aur command-line programs bhi likhe ja sakte hain. HTML structure deta hai, CSS style deta hai, aur JavaScript behavior sambhalti hai.

console.log("Namaste, JavaScript!");
alert("Ye message browser mein dikhega");

console.log() debugging aur output dekhne ke kaam aata hai. Browser ka alert() sirf chhote demo ke liye use karein.

Is code ka matlab

  • console.log(...) diye gaye text ko developer Console mein print karta hai.
  • Quotes ke andar likha hua text string hota hai; yahan wahi message print ho raha hai.
  • alert(...) browser mein popup dikhata hai. Ye user ko rokta hai, isliye asli websites mein aam taur par page par hi message dikhate hain.
  • JavaScript ke statements aksar alag lines mein likhe jaate hain. Semicolon optional ho sakta hai, lekin ek style chun kar consistent rehna achha hai.

2. Variables aur data types

Variable ek naam diya hua box samjhein jisme value rakhte hain. Naye code mein badalne wali value ke liye let, aur dobara assign na hone wale reference ke liye const use karein. Purana var aam taur par avoid karein.

const naam = "Aman";       // string
let umar = 20;             // number
let studentHai = true;     // boolean
let address;               // undefined
const khaali = null;       // jaan-boojhkar khaali

console.log(typeof naam);  // "string"
console.log(typeof umar);  // "number"

JavaScript ke common primitive types: string, number, boolean, undefined, null, bigint aur symbol. Arrays aur objects reference types hain.

Yaad rakhein: const object ya array ko immutable nahi banata; sirf us variable ko kisi naye object/array se reassign karne se rokta hai.
const rang = ["laal", "neela"];
rang.push("hara");         // allowed
// rang = [];              // error: const ko reassign nahi kar sakte

Is lesson ke points

  • const naam = ... naam ka variable banakar usmein value rakhta hai. const ko banate waqt value dena zaroori hai.
  • let ko baad mein nayi value di ja sakti hai; const wale variable ko dobara assign nahi kar sakte.
  • String text hai, number ginti/measurement hai, boolean sirf true ya false hai.
  • Value na di ho to value undefined hoti hai; null ka matlab jaan-boojhkar khaali value hai.
  • typeof value ka type batata hai. typeof null JavaScript ki purani quirk ki wajah se "object" deta hai.
  • Array/object ko const se banane ke baad uske andar ke items/properties badal sakte hain; variable ko kisi doosre array/object se replace nahi kar sakte.

3. Operators aur type conversion

const a = 10;
const b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1 (remainder)

console.log(5 === "5"); // false: value aur type dono compare
console.log(5 == "5");  // true: type conversion hota hai

Comparison ke liye aam taur par === aur !== use karein. && (and), || (or), aur ! (not) logical operators hain.

const scoreText = "42";
const score = Number(scoreText);
console.log(score + 8); // 50

const naamInput = "";
const dikhaneWalaNaam = naamInput || "Guest"; // "Guest"

Operators ka matlab

  • + jodta hai, - ghatata hai, * guna karta hai, / bhaag karta hai aur % bhaag ka remainder deta hai.
  • === value aur type dono ko compare karta hai. == pehle type badalne ki koshish karta hai, isliye aksar confusing result aa sakta hai.
  • && ka matlab dono conditions true; || ka matlab kam se kam ek true; ! result ko ulta karta hai.
  • Number("42") text ko number mein badalta hai. Galat numeric text ko convert karne par NaN mil sakta hai.
  • || empty string, zero, false, null aur undefined par right-side fallback leta hai. Sirf null/undefined ke liye ?? istemal hota hai.

4. Conditions aur loops

const marks = 76;

if (marks >= 80) {
  console.log("Bahut achha");
} else if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Dobara koshish karein");
}

const status = marks >= 40 ? "Pass" : "Fail"; // ternary

Ek value ke multiple cases ke liye switch ka use kar sakte hain:

const day = "Somvar";
switch (day) {
  case "Somvar":
    console.log("Naya hafta");
    break;
  case "Ravivar":
    console.log("Chhutti");
    break;
  default:
    console.log("Aam din");
}

Repeated kaam ke liye loop use karein:

for (let i = 1; i <= 3; i++) {
  console.log("Ginti:", i);
}

let count = 0;
while (count < 3) {
  count++;
}

for (const rang of ["laal", "neela"]) {
  console.log(rang);
}

Conditions aur loops ka matlab

  • if condition true hone par block chalata hai; else if doosri condition check karta hai; else tab chalta hai jab upar ki koi condition true na ho.
  • marks >= 40 ek comparison hai. Iska result boolean hota hai: true ya false.
  • Ternary condition ? valueA : valueB chhota if/else hai aur aksar value chunne ke liye use hota hai.
  • switch ek hi value ke alag cases check karta hai. break case ke baad switch se bahar nikalta hai; default koi case match na hone ka fallback hai.
  • for loop mein pehla hissa shuruaat (i = 1), doosra chalne ki condition aur teesra har chakkar ke baad update hai.
  • while condition true rehne tak chalta hai. Condition ko update na karne par infinite loop ban sakta hai.
  • for...of array ke har item par ek-ek baar chalta hai.

5. Functions aur scope

Function reusable code block hai. Inputs parameters hote hain aur return result deta hai.

function jodo(a, b) {
  return a + b;
}
console.log(jodo(4, 6)); // 10

const guna = function (a, b) {
  return a * b;
};

const greet = (naam) => `Namaste, ${naam}!`;
console.log(greet("Aman"));

Arrow function ka short form: (x) => x * 2. Function ke bahar declare kiya variable global/module scope mein ho sakta hai; function ke andar let ya const se banaya variable us block tak hi rehta hai.

function discount(price, percent = 10) {
  return price - price * percent / 100;
}
console.log(discount(200)); // 180
console.log(discount(200, 25)); // 150

Function ke points

  • function jodo(a, b) function define karta hai; a aur b parameters hain, jinhe call karte waqt values milti hain.
  • jodo(4, 6) function ko call karta hai. Yahan 4 aur 6 arguments hain.
  • return function ka result wapas bhejta hai. return ke baad us function call ka kaam khatam ho jaata hai.
  • Function expression ko variable mein rakha jaata hai; arrow function iska ek chhota syntax hai.
  • percent = 10 default parameter hai: doosri value na dein to 10 use hota hai.
  • Scope batata hai variable kahan available hai. let/const se bane block variables apne braces ke bahar available nahi hote.

6. Arrays

Array ordered list hoti hai. Index zero se shuru hota hai.

const fruits = ["aam", "seb", "kela"];
console.log(fruits[0]); // "aam"
fruits.push("angoor");  // aakhir mein jodo
fruits.pop();           // aakhri item hatao
console.log(fruits.length);

Array methods kaafi kaam aate hain:

const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(n => n * 2);
const even = numbers.filter(n => n % 2 === 0);
const found = numbers.find(n => n > 3);
const total = numbers.reduce((sum, n) => sum + n, 0);

console.log(doubled); // [2, 4, 6, 8, 10]
console.log(even);    // [2, 4]
console.log(found);   // 4
console.log(total);   // 15

map aur filter naya array banate hain. sort() original array ko badalta hai; numbers ko sahi order mein sort karne ke liye comparator dein:

const values = [10, 2, 30];
const sorted = [...values].sort((a, b) => a - b);
console.log(sorted); // [2, 10, 30]

Array ke points

  • Array ek order wali list hai; pehla item index 0, doosra index 1 par hota hai.
  • push aakhir mein item jodta hai; pop aakhri item nikalta hai; length item ki tadaad deta hai.
  • map har item ko badal kar utne hi items ka naya array banata hai; yahan har number double hua.
  • filter condition pass karne wale items rakhta hai; find pehla matching item deta hai.
  • reduce items ko mila kar ek result banata hai; yahan running sum ban raha hai. Aakhri 0 shuruaati sum hai.
  • Default sort() text ki tarah sort kar sakta hai. (a, b) => a - b numeric ascending order batata hai.
  • [...values] array ki shallow copy hai; isse original array ko sort karne se bachaya gaya.

7. Objects aur JSON

Object related data ko key-value pairs mein rakhta hai.

const user = {
  naam: "Aman",
  umar: 20,
  active: true,
  greet() {
    return `Namaste, main ${this.naam} hoon`;
  }
};

console.log(user.naam);
console.log(user["umar"]);
user.umar = 21;
console.log(user.greet());

Destructuring aur spread se objects kaam karna aasan hota hai:

const { naam, umar } = user;
const updatedUser = { ...user, umar: 22 };
console.log(naam, umar);
console.log(updatedUser);

JSON data exchange ka text format hai. JSON mein methods/functions nahi hote.

const jsonText = JSON.stringify({ naam: "Aman", umar: 20 });
const parsed = JSON.parse(jsonText);
console.log(parsed.naam);

Object aur JSON ke points

  • Object mein har property ka naam (key) aur uski value hoti hai, jaise naam: "Aman".
  • user.naam dot notation hai; user["umar"] bracket notation hai. Bracket notation tab kaam aata hai jab key variable mein ho.
  • this.naam yahan us object ki naam property leta hai jiske through greet() call hua.
  • Destructuring object se properties nikal kar variables banata hai. Spread ... properties copy karta hai; baad mein likhi property purani value ko overwrite kar sakti hai.
  • JSON.stringify JavaScript value ko JSON text banata hai; JSON.parse JSON text ko wapas JavaScript value banata hai.
  • JSON parse karte waqt invalid text error de sakta hai. External data parse karte waqt error handling karein.

8. Strings, numbers aur dates

const first = "Java";
const second = "Script";
const full = `${first}${second}`;

console.log(full.toUpperCase());
console.log("  hello  ".trim());
console.log("JavaScript".includes("Script"));
console.log("a,b,c".split(","));

const amount = 12.345;
console.log(amount.toFixed(2)); // "12.35" (string)

Date banane ke liye Date object use karein. Date display user ke timezone ke hisaab se badal sakta hai.

const now = new Date();
console.log(now.toISOString());
console.log(now.getFullYear());

Text, number aur date methods

  • Template string backtick ` se banti hai; ${...} ke andar variable ya expression likh sakte hain.
  • toUpperCase() text ko uppercase karta hai, trim() shuru/aakhir ke spaces hataata hai, includes() poochta hai ki text maujood hai ya nahi.
  • split(",") comma par text ko array mein todta hai.
  • toFixed(2) do decimal places dikhata hai, lekin result string hota hai; calculation ke liye number mein convert karna pad sakta hai.
  • new Date() abhi ka samay banata hai; toISOString() standard UTC text deta hai, jabki local date display timezone se badal sakta hai.

9. Errors aur debugging

Developer tools mein Console aur Sources/Debugger ka use karein. console.log(), breakpoints, aur step-through debugging se values check karein.

function divide(a, b) {
  if (b === 0) {
    throw new Error("Zero se divide nahi kar sakte");
  }
  return a / b;
}

try {
  console.log(divide(10, 0));
} catch (error) {
  console.error("Calculation fail hui:", error.message);
}

Input validation karein aur error ko chupane ke bajay user ya developer ko useful feedback dein.

Error handling ka matlab

  • throw new Error(...) batata hai ki function valid result nahi de sakta.
  • try ke andar risky code chalta hai; error aaye to normal flow ruk kar catch block mein jaata hai.
  • error.message error ka readable message hai; console.error ise Console mein error ke roop mein dikhata hai.
  • Debugger mein breakpoint lagane se execution rukta hai; phir variables ko dekhte hue step-by-step aage badh sakte hain.

10. HTML ke saath DOM

DOM browser mein HTML page ka object representation hai. Is example ko HTML file mein script ke saath run karein:

<h1 id="title">Purana title</h1>
<p class="message">Yahan message aayega</p>

<script>
  const title = document.querySelector("#title");
  const message = document.querySelector(".message");

  title.textContent = "Naya title";
  message.textContent = "JavaScript ne page update kiya!";
  title.classList.add("highlight");
</script>

HTML content dikhane ke liye user-provided text ke saath innerHTML ke bajay textContent use karein. Naya element banane ka example:

const item = document.createElement("li");
item.textContent = "Naya item";
document.querySelector("#list").append(item);

DOM ke points

  • document current web page ko represent karta hai; DOM us page ka tree hota hai jise JavaScript padh aur badal sakti hai.
  • querySelector CSS selector se pehla matching element dhoondhta hai. #title id aur .message class ko select karta hai.
  • textContent element ke andar ka plain text badalta hai; classList.add CSS class jodta hai.
  • createElement naya element banata hai; append use page ke kisi element ke andar jodta hai.
  • Agar selector ko matching element na mile to result null hota hai. Element ka hona confirm karein ya script ko HTML ke baad load karein.

11. Events aur forms

Event listener click, typing ya form submit par function chalata hai.

<button id="helloButton">Click karein</button>
<p id="output"></p>

<script>
  const button = document.querySelector("#helloButton");
  const output = document.querySelector("#output");

  button.addEventListener("click", () => {
    output.textContent = "Button click hua!";
  });
</script>

Form submit hone par page reload rokne ke liye preventDefault():

<form id="nameForm">
  <input id="nameInput" required placeholder="Apna naam">
  <button>Submit</button>
</form>
<p id="greeting"></p>

<script>
  document.querySelector("#nameForm").addEventListener("submit", (event) => {
    event.preventDefault();
    const name = document.querySelector("#nameInput").value.trim();
    document.querySelector("#greeting").textContent = `Namaste, ${name}!`;
  });
</script>

Events aur forms ke points

  • Event user ya browser ki activity hai, jaise click, input ya submit.
  • addEventListener("click", callback) kehta hai: click hone par callback function chalao.
  • Form ka default submit page reload kar sakta hai; event.preventDefault() us default behavior ko rokta hai.
  • input.value field ka text deta hai; trim() extra spaces hataata hai.
  • required browser ki basic validation hai. App ko phir bhi input check karna chahiye, kyunki har validation sirf HTML par bharosemand nahi hoti.
  • User ka text page par dikhane ke liye textContent safe choice hai.

12. Asynchronous JavaScript

Network ya timer jaise kaam mein waqt lag sakta hai. Promise baad mein milne wale result ko represent karta hai. async/await asynchronous code ko padhne layak banata hai.

console.log("Pehle");
setTimeout(() => console.log("Baad mein"), 500);
console.log("Doosra");

Network request ka example (browser):

async function loadUser() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users/1");
    if (!response.ok) {
      throw new Error(`Request fail: ${response.status}`);
    }
    const user = await response.json();
    console.log(user.name);
  } catch (error) {
    console.error("User load nahi hua:", error);
  }
}

loadUser();

Har await ko aise function ke andar likhein jo async ho. Network error aur non-success HTTP response dono ko handle karein; fetch har HTTP error par apne aap reject nahi hota.

Async code ka matlab

  • JavaScript aam taur par ek waqt mein ek hi kaam chalati hai. Timer/network ke intezar mein poora page rokne ke bajay baaki kaam chalte rehte hain.
  • setTimeout callback ko diye gaye minimum delay ke baad chalane ke liye schedule karta hai; isliye output pehle, doosra, phir baad mein hota hai.
  • Promise future result ko represent karta hai: abhi pending, baad mein fulfilled (success) ya rejected (failure).
  • async function hamesha Promise return karta hai. await us Promise ke result ka intezar karta hai bina poore browser ko freeze kiye.
  • fetch request bhejta hai; response.ok HTTP success check karta hai; response.json() response body ko JavaScript data mein badalta hai.
  • try/catch request ya JSON conversion ki failure sambhalta hai. HTTP 404 jaise response ke liye response.ok khud check karna hota hai.

13. Browser storage

localStorage browser mein chhota text-based data reload ke baad bhi rakhta hai. Ismein sensitive information, jaise password, store na karein.

const settings = { theme: "dark" };
localStorage.setItem("settings", JSON.stringify(settings));

const savedText = localStorage.getItem("settings");
const savedSettings = savedText ? JSON.parse(savedText) : null;
console.log(savedSettings);

localStorage.removeItem("settings");

sessionStorage tab/session tak rehta hai. Dono browser-specific hain aur Node.js mein available nahi hote.

Storage ke points

  • Storage mein key aur string value rakhi jaati hai; object ko pehle JSON.stringify karke text banana hota hai.
  • setItem save karta hai, getItem padhta hai aur key na mile to null deta hai; removeItem ek key hataata hai.
  • savedText ? ... : null check karta hai ki data mila ya nahi, uske baad hi JSON parse hota hai.
  • localStorage browser band/reload ke baad bhi rehta hai; sessionStorage aam taur par tab band hone tak rehta hai.
  • Storage same browser/origin ke liye hota hai aur limited hota hai. Password ya secret token jaise sensitive data yahan na rakhein.

14. Modules aur npm

Modules code ko alag files mein baantte hain. Browser mein entry HTML par type="module" lagayein.

// math.js
export function add(a, b) {
  return a + b;
}

// app.js
import { add } from "./math.js";
console.log(add(2, 3));
<script type="module" src="./app.js"></script>

npm Node.js ke saath aane wala package manager hai. Project folder mein npm init -y se package setup karein; kisi package ko add karne se pehle uski documentation aur zaroorat check karein.

Modules aur npm ke points

  • export doosri file ko function/value istemal karne deta hai; import exported cheez ko laata hai.
  • Named export mein import ka naam braces ke andar aur same hona chahiye; file path bhi sahi hona zaroori hai.
  • type="module" browser ko batata hai ki file ES module hai. Modules ko aam taur par local web server se chalayein; seedha file:// se kholne par browser rok sakta hai.
  • npm packages install, update aur scripts chalane mein madad karta hai. package.json project metadata, dependencies aur commands rakhta hai.
  • Har dependency project mein extra code laati hai; sirf trusted aur zaroori packages install karein.

15. Modern JavaScript concepts

Optional chaining aur nullish coalescing

const city = user.profile?.address?.city ?? "Pata nahi";
console.log(city);

?. missing/null value par safe access deta hai. ?? sirf null ya undefined par fallback deta hai; || zero aur empty string par bhi fallback dega.

Set aur Map

const unique = new Set([1, 1, 2, 3]);
console.log([...unique]); // [1, 2, 3]

const scores = new Map();
scores.set("Aman", 90);
console.log(scores.get("Aman"));

Class

class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    return `${this.name} awaaz karta hai`;
  }
}

const dog = new Animal("Dog");
console.log(dog.speak());

Class JavaScript ke prototype-based object system ka syntax hai. Har problem ke liye class zaroori nahi; simple functions aur objects bhi achha design ho sakte hain.

Promises ko saath chalana

async function loadBoth() {
  const [first, second] = await Promise.all([
    fetch("/api/first").then(response => response.json()),
    fetch("/api/second").then(response => response.json())
  ]);
  return { first, second };
}

Modern features ka matlab

  • user.profile?.address?.city har level par check karta hai. Beech ki property missing ho to crash ke bajay undefined milta hai.
  • ?? "Pata nahi" sirf null/undefined par default deta hai; valid value jaise empty string ya zero ko nahi badalta.
  • Set duplicate values nahi rakhta; [...unique] Set ko array mein badalta hai.
  • Map key-value data rakhta hai; set save karta hai aur get key ki value padhta hai.
  • class objects banane ka reusable blueprint hai. constructor naya object bante waqt chalta hai; new object banata hai.
  • Promise.all independent Promises ko ek saath start karke sabke results ka intezar karta hai. Koi Promise fail ho to combined Promise bhi reject hota hai.

16. Practice project: To-do list

Is mini project mein DOM, events, arrays aur localStorage ek saath use hote hain. Isse todo.html naam ki file mein save karke browser mein kholein.

<!doctype html>
<html lang="hi">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Meri To-do List</title>
<h1>Meri To-do List</h1>
<form id="todoForm">
  <input id="todoInput" required placeholder="Naya kaam">
  <button>Jodein</button>
</form>
<ul id="todoList"></ul>
<script>
  const form = document.querySelector("#todoForm");
  const input = document.querySelector("#todoInput");
  const list = document.querySelector("#todoList");
  let todos = JSON.parse(localStorage.getItem("todos") || "[]");

  function render() {
    list.replaceChildren();
    todos.forEach((todo, index) => {
      const item = document.createElement("li");
      const text = document.createElement("span");
      text.textContent = todo;

      const removeButton = document.createElement("button");
      removeButton.type = "button";
      removeButton.textContent = "Hatao";
      removeButton.addEventListener("click", () => {
        todos.splice(index, 1);
        saveAndRender();
      });

      item.append(text, " ", removeButton);
      list.append(item);
    });
  }

  function saveAndRender() {
    localStorage.setItem("todos", JSON.stringify(todos));
    render();
  }

  form.addEventListener("submit", (event) => {
    event.preventDefault();
    const value = input.value.trim();
    if (!value) return;
    todos.push(value);
    input.value = "";
    saveAndRender();
  });

  render();
</script>
</html>

Khud se add karein: kaam complete mark karne ka checkbox, saare kaam clear karne ka button, aur empty list ka message.

Project kaise kaam karta hai

  • Shuru mein querySelector form, input aur list ke HTML elements ko JavaScript variables mein pakadta hai.
  • localStorage.getItem purane tasks laata hai; JSON.parse unhe array banata hai. Pehli baar data na ho to [] khaali array milta hai.
  • render() purani list saaf karke har task ke liye naya li, text aur delete button banata hai.
  • Delete button click par splice(index, 1) us index ka ek task hataata hai.
  • saveAndRender() pehle updated array ko JSON text bana kar save karta hai, phir screen dobara banata hai.
  • Submit handler reload rokta hai, input se spaces hataata hai, khaali text ko chhodta hai, task array mein jodta hai aur input clear karta hai.
  • Har task ko textContent se dikhaya gaya hai, isliye user ka input HTML ke roop mein execute nahi hota.
  • render() ka aakhri call page khulte hi saved tasks dikhata hai.

Is learning order ka matlab

  • HTML/CSS se page banana seekhein, phir JavaScript se us page ke elements badlein aur user interactions sambhalein.
  • Git changes ka history rakhta hai; DevTools errors dekhne mein; npm project tools/dependencies sambhalne mein madad karte hain.
  • Testing se pata chalta hai ki code alag inputs par sahi chal raha hai. Chhote functions test aur reuse karna aasaan hota hai.
  • React/Vue user interface banane ke tools hain; Node.js/Express server-side JavaScript ke liye; TypeScript JavaScript mein static type checking jodta hai. Sab ek saath seekhna zaroori nahi.
  • Chhote projects concepts ko jodte hain aur portfolio mein dikhane layak kaam dete hain.
JavaScript mein “sab kuch” ek baar mein yaad karna zaroori nahi. Basics samajhkar projects banana, errors padhna aur documentation dekhna sabse achha learning path hai.

Yeh ek beginner-to-advanced learning roadmap hai, har JavaScript API ki poori reference nahi. Examples ko khud run aur modify karke seekhein.
